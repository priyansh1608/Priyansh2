QUESTION 2 : Pick any one real-world application of Reinforcement Learning
             (such as game AI, robotics, self-driving cars, or recommendation
             systems) and explain step-by-step how an agent, environment, 
             actions, and rewards would work in that scenario.
             <br><br><em><strong>Hint:</strong> Use your own words and pick
            an example you find interesting, like how a Zomato recommendation
            engine could use RL to suggest restaurants.</em

------------------------------------------------------------------------------------

ANSWER:

REAL-WORLD APPLICATION:
Zomato Restaurant Recommendation System


Reinforcement Learning could be used to improve restaurant
recommendations in a food delivery application.


STEP 1 - AGENT:

The recommendation system acts as the RL agent.

The agent decides which restaurants should be recommended to the user.


STEP 2 - ENVIRONMENT:

The food delivery application and the user's interaction with the
recommended restaurants form the environment.


STEP 3 - STATE:

The current state can include information such as:

- User location
- Previous orders
- Favourite cuisines
- Time of day
- Previous ratings
- User's restaurant preferences


STEP 4 - ACTIONS:

The agent can take actions such as:

- Recommend Restaurant A
- Recommend Restaurant B
- Recommend Restaurant C
- Recommend a different cuisine
- Show restaurants near the user's location


STEP 5 - REWARDS:

The system can receive rewards based on the user's response.

For example:

+10 -> User places an order
+5  -> User clicks on the restaurant
+3  -> User gives a good rating
-5  -> User ignores the recommendation
-10 -> User gives a poor rating


STEP 6 - LEARNING:

The agent observes the rewards and learns which recommendations are
more useful for the user.

For example, if a user frequently orders Gujarati food and gives
high ratings, the system can learn that Gujarati restaurants may
be useful recommendations for that user.


CONCLUSION:

By continuously learning from user actions and rewards, the RL agent
can improve future restaurant recommendations.
